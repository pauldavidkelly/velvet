# Velvet

A touch-typing tutor that teaches a person their own programmable keyboard, its layers, thumb keys and special functions included, not just the letters. It starts with the MoErgo Glove80.

## Language

**Keymap**:
A person's configured set of bindings across every layer of their keyboard. The tutor teaches a specific Keymap, not a generic layout.
_Avoid_: Layout (it's ambiguous between the physical arrangement and the bindings), config

**Layer**:
A named set of bindings that sits over the same physical keys. You reach it by holding or toggling another key.

**Host layout**:
The keyboard layout the computer's OS is set to, such as UK ISO. It decides which character each keycode from the keyboard produces.
_Avoid_: OS layout, locale

**Unlocking**:
Introducing new keys to practise a few at a time, once the person has mastered the keys they already have.
_Avoid_: Levelling, progression

**Keymap analysis**:
An assessment of how easy a Keymap's bindings are to reach, which shows bindings worth moving. It's separate from teaching the Keymap.
